# Documentation Index

Use these folders by purpose:

- `architecture/` - system architecture, sequence diagrams, and rendered diagram assets.
- `integration/` - embedding, Aeron integration, ABI, and wire/schema policies.
- `release/` - client release processes.
- `reports/phase-1-7/` - Phase 1 through Phase 7 completion evidence.
- `reports/phase-8/` - Phase 8 completion, onboarding, and card evidence.
- `testing/` - CI test profiles and benchmark baseline documentation.
